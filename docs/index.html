A free, open-source iOS device manager that replaces $50/year tools. Backups, messages, photos, app management, device cloning, and more. No subscriptions. No iCloud. No compromises.

Everything you need. Nothing you don't.

Device Dashboard

Auto-detect connected devices. View model, iOS version, serial, UDID, IMEI, battery health, and storage breakdown. Supports iPhone, iPad, and iPod touch.

Smart Backups

Full and incremental backups. Browse contents via Manifest.db. Extract individual files. Scheduled automatic backups via USB or Wi-Fi.

Time Machine Restore

3D animated backup browser inspired by macOS Time Machine. Scroll through backup history and restore any snapshot with one click.

Message Export

iMessage, SMS, and WhatsApp conversations. Export to CSV, HTML, JSON, or plain text. HTML styled with native chat bubbles.

Photo Extraction

Browse Camera Roll from backup. Filter by type. Batch extract with original filenames and structure preserved.

App Management

Install/remove IPAs. Browse app data in backups. Extract individual app containers. Fallback chain supports all ideviceinstaller versions.

File Browser + Drag-and-Drop

Mount device filesystem via AFC. Navigate, copy, delete files. Drop files from Finder to transfer directly to device.

Device Clone

Transfer all data between two devices. Backup source, restore to destination. Progress tracking through both phases.

Diagnostics

Battery health with mAh details. Storage breakdown by category. Real-time syslog streaming with color-coded levels.

Health Data

Browse all HealthKit data types. View samples, workouts, and activity summaries. Apple Watch Activity rings included.

Notes, Contacts, Calendar

Apple Notes with folder browsing. Contacts with vCard export. Calendar events with ICS export. Call log and Safari history.

Localized

Available in English, Arabic, Spanish, French, German, Japanese, and Chinese. .phosphor archive format for portable backups.
